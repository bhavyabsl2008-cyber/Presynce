# Origin UI Inspiration & Primitive Engineering

Origin UI provides a benchmark for clean component primitive construction and modular component design within modern React and Tailwind CSS architectures. Built on top of accessible, unstyled primitives (such as Radix UI), Origin UI demonstrates how component contracts should be structured for high reliability, strict type safety, and effortless composition.

From Origin UI, we extracted principles of component encapsulation and props API clarity. Components in Presynce V2—such as `SemanticStatus`, `CompactThreshold`, and `DecisionRow`—are engineered with strict TypeScript interfaces that separate presentation props from state derivation logic. Pure functions transform raw attendance data into status labels, ensuring components remain predictable, testable, and free of side effects.

Furthermore, Origin UI inspired our disciplined approach to micro-interactions. Actionable primitives incorporate tactile visual states—such as subtle background field shifts on hover (`#F5F2FF`), immediate press feedback, and clear focus outlines—providing immediate physical response without overwhelming the user with unnecessary visual noise.
